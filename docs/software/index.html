Code bases and Algorithms

The group’s algorithm library, research infrastructure and field tools, plus every repository under @jepperich69

Open code bases and algorithms by Jeppe Rich (DTU), including optimization and sampling libraries.

The three code bases below are the core of the group’s software. Algorithms developed for individual papers are moved into jr_optlib, so the library is the one place to find them. Paper-specific code is also linked from each paper’s entry in Papers, and collaborative projects are described under Projects.

Python · Optimization, sampling and choice-model library

jr_optlib

The group's library of optimization and sampling primitives. Each primitive ships with an oracle, an independent check that re-derives a property the true answer must have (feasibility, a duality or gap certificate, agreement with an independent solver, or an invariant under a known transformation). A solve is therefore followed by a certification, and every result is labelled CERTIFIED, CHECKED, FAIL or UNVALIDATED. The runtime needs only NumPy; SciPy, Gurobi and numba are optional. The library contains:

  • Transportation and optimal transport: IPF / raking (Furness), entropic optimal transport (Sinkhorn, with dual scalings), exact min-cost transport by LP, and a family of rounders that turn fractional plans into integer tables without breaking the marginals.
  • Population synthesis and integerization: sparse N-dimensional IPF over long record tables, and a floor split, anchor-conditioned PPS and anchor-preserving swap repair that give an integer population matching the controlling margins.
  • Entropy-guided set cover: the RICH entropy relaxation with dual-guided rounding, plus an exact MIP, a restricted polish step and benchmark instances with known optima.
  • Assignment under risk: closed-form entropic risk of Gaussian costs, a convex QP over the Birkhoff polytope, exact Hungarian solutions for the independent case, and a MIQP for correlated costs.
  • Chance-constrained selection sampling: a Metropolis–Hastings sampler with O(1) incremental updates (optionally JIT-compiled, about 50 times faster) that bounds sample-average-approximation optima.
  • Generic MCMC and dual ascent: Metropolis–Hastings, simulated annealing, temperature-ladder burn-in, a vehicle-scheduling local search, and Lagrangian subgradient dual ascent.
  • Discrete choice: numerically stable multinomial and nested logit probabilities, logsums, stochastic user-equilibrium route shares, and recursive-logit (route-free) link assignment.
  • Dynamic programming and reinforcement learning: exact finite-horizon backward induction over tensor grids, and tabular Q-learning, both risk-neutral and risk-sensitive.
  • Nonlinear programming and routing: coordinate-wise NLP block solves and grid shortest-distance helpers.
  • Oracle catalogue: generic gap, differential and metamorphic certificates, and about twenty domain-specific certifiers, one or more for each primitive above.

PowerShell / Python · AI research infrastructure

ai-infrastructure (AI_auto)

A local, file-based backbone for running long-lived projects with AI agents. Context, decisions, sources, code, logs and handovers live in ordinary files, so work survives across sessions, agents and machines. One command wrapper, helpi, drives it all. Functionality:

  • Project continuity: every project gets a permanent brief, a session log and a generated handover, so Claude Code, Codex and Gemini read the same context and continue one another's work.
  • Project scaffolding: one command creates a paper project or a generic project (software, teaching, administration) with the full continuity layer.
  • Overleaf and LaTeX: two-way Git synchronization with Overleaf, local compilation, manuscript snapshot tags and rollback.
  • Research skills: referee-style paper review, pre-submission grilling, reviewer-response loops, style editing calibrated on the author's own papers, and journal submission packages.
  • Verification: SymPy checks of the mathematics in a manuscript, and certification of optimization results against jr_optlib oracles.
  • Multi-agent work: Convergence Forums (structured debate between Claude, Codex and Gemini) and background multi-agent pipelines.
  • Cross-project context: feeder links let one project inherit a compact digest of another; a network graph and a status dashboard cover all projects.
  • Compute: remote job submission to a home compute server, which is woken on demand, and profiling guidelines.
  • Operations: automated backups, setup and restore on a new machine, a generated inventory of installed research software, and a known-issues register.
  • NoteTaker bridge: dictated notes and photos from a phone arrive in the right project (see below).

Web app (PWA) · Voice and photo capture

notetaker-app

A phone app (an installable web app) that captures ideas in the field and files them in the right research project. Functionality:

  • Voice notes: record in the browser, pick the project from a list synchronized with the infrastructure, and send.
  • Photos: take a picture with the phone camera, e.g. of a whiteboard, a page or a site, or import an existing image, and file it in the same way.
  • Sharing in: recordings shared from other apps are received and can be assigned to a project afterwards.
  • Transcript and summary: each note comes back with a transcript and a short summary, with a notification when it is ready.
  • Offline-safe: notes are queued on the phone and uploaded with automatic retry when the connection returns, so nothing is lost.
  • Into the workflow: notes pass through a private spool into the project folders, where the AI agents pick them up at the next session.
